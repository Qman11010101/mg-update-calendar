# 音ゲー更新カレンダー

ビルドや外部ライブラリを必要としない静的サイト。`index.html`が同じディレクトリの`entries.json`（抽出結果のschema_version 2・3・4・5・6・7）を読み込む。

## ローカル表示

リポジトリのルートで実行し、http://localhost:8000/ を開く。

```powershell
python -m http.server 8000 --directory docs
```

JSONをfetchするため、HTMLファイルの直接オープンではなくHTTPサーバー経由で表示する。

## データ更新

リポジトリのルートにある抽出結果をコピーする。コピーした公開用JSONもGitに含める。

```powershell
Copy-Item entries.json docs/entries.json
```

`docs/.gitignore`は、この公開用JSONだけを親ディレクトリのJSON除外設定から除外する。

## GitHub Pages

GitHub Actions（`.github/workflows/pages.yml`）でデプロイする。リポジトリのSettings → Pagesで、Sourceを「GitHub Actions」にしておく。
`main`へのpushで`docs/`配下またはワークフローが変更されたときに実行される。ActionsタブのRun workflowから手動でも実行できる。
公開するのは`index.html`・`calendar.js`・`lib/`・`style.css`・`entries.json`のみで、このREADMEは含めない。公開するファイルを増やす場合はワークフローのコピー対象に追加する。

`lib/`にはDOMに依存しない処理（`dates.js`は日付計算、`entries.js`は読み込み・重複統合・親イベントのまとめ・一覧の分類）を置き、`calendar.js`は描画と操作だけを担う。ES Modulesで読み込むため、表示にはHTTPサーバーが必要。
Jekyllによるビルドは行わない。CSS・JavaScript・JSONは相対パスで参照する。

参照：[GitHub Pagesの公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 表示仕様

- 初期表示は日本時間の今月。前月・翌月・月指定・今月への移動に対応する。
- 画面は「いま開催中」「月間カレンダー」「日別パネル」「開催期間タイムライン」で構成する。
  - いま開催中：今日（日本時間）を含む期間のエントリを1件ずつカードに表示し、終了が近い順に並べる。残り日数と経過の進捗バーを表示し、最初の8枚以外は展開して表示する。各エントリ自身の日時と絞り込み条件を使う。
  - 月間カレンダーの各日には、その日に始まる項目をゲームごとの件数（1件なら題名）で表示し、終了する項目の件数を添える。  - 日付を押すと、日別パネルに「この日から」「この日まで」「開催中（残り日数）」の一覧を表示する。初期選択は今日（今月以外では最初に項目が始まる日）。
  - 終了日のある期間はタイムライン（ガントチャート）に1行ずつ、ゲーム別にまとめて表示する。ゲーム単位で折りたためる。月をまたぐ部分は点線で示し、今日の位置に縦線を引く。
- 終了日未定（`open_ended`）と終了日のない単日項目は、開始日にのみ表示する。
- エントリの種類は、種類ごとに異なる淡い背景色と濃い文字色の角丸タグで表示する。開催中カードにもその項目の種類を表示する。件数・日付はタグの外に表示する。
- ゲーム・種類・キーワードで絞り込める。キーワードはタイトル・曲名・記事タイトルを対象とする。
- 開始日不明の項目は月間カレンダーに配置せず、別の一覧に表示する。この一覧にも絞り込み条件を適用する。
- 要確認の項目も掲載するが、要確認ラベルと確認理由は表示しない。
- 詳細には対象楽曲と関連記事を表示する。関連記事の記事タイトルは公式のお知らせへのリンクとし、記事公開日を添える。統合した項目にはすべての関連記事を表示する。告知の日付表記と抽出に用いた原文の根拠は表示しない。
- カレンダー配置・期間・残り日数には`calendar_start`・`calendar_end`を使う。フィールドのない項目は正式な日付を使う。
- 詳細の日時は告知の表記を保持し、前日補正した項目には最終利用日も表示する。
- `cancellations`は通常のエントリとして表示しない。取り消し対象の照合は行わない。
- ゲーム・種類・タイトル・正式な開催日時・対象サービス・期間指定・対象曲・カレンダー配置日が完全一致する項目を表示時に1件に統合する。開始日不明の項目は統合しない。抽出JSONは記事別に保持し、表示用の統合結果にも各記事の出典・日付表記・原文根拠・確信度を残す。表記や分類が異なる項目の推測による統合は行わない。
- 狭い画面では日別パネルをカレンダーの下に置き、セルはゲーム色の件数バッジだけにする。タイムラインは横にスクロールでき、項目名の列は固定する。
